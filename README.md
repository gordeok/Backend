# Backend

## Branch 규칙
- `main` : 최종 배포 브랜치
- `feat/깃허브아이디` : 개인 개발 브랜치
- 예시: `feat/ej3131`

## Commit 규칙
- `feat` : 기능 추가
- `fix` : 버그 수정
- `docs` : 문서 수정
- `refactor` : 코드 개선
- `chore` : 설정 및 기타 작업
- `test` : 테스트 코드

## Commit 예시
- `feat: 회원가입 API 구현`
- `fix: 게시글 조회 오류 수정`
- `chore: application.yml 설정 수정`
